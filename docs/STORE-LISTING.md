# 플레이 스토어 등록정보 — 붙여넣기용 (2026-09-05)

Play Console 의 **스토어 설정 → 기본 스토어 등록정보** 에 그대로 넣으면 된다.
자산은 `store-assets/` 에 있다(저장소에는 안 올라간다 — `node scripts/store-shots.mjs` 로 다시 뽑는다).

> ⚠️ 여기 적힌 기능은 **로그인 없이도 화면에서 보이는 것만** 골랐다.
> 코드에 있어도 화면에 안 나오는 것을 설명에 적으면 반려된다(BLOCKPOP 이 그렇게 한 번 걸렸다).

```
오늘 뭐 먹지? - 먹자냥
```

## 간단한 설명 (80자)

```
못 정하겠는 메뉴, 월드컵으로 정하자! 친구들과 투표하고 주변 맛집까지 한 번에.
```
(공백 포함 42자)

```
"아무거나"는 이제 그만. 메뉴 월드컵·랜덤 추천·모임 투표로 3분 만에 메뉴 결정!
```
```
오늘 뭐 먹지? 고민될 땐 먹자냥. 월드컵으로 뽑고, 친구들과 투표하고, 바로 찾아가기.
```

## 그래픽 자산

| 항목 | 파일 | 규격 |
| --- | --- | --- |
| 앱 아이콘 | `public/icon-512.png` | 512×512 ✅ |
| 그래픽 이미지 | `store-assets/feature-graphic.png` | 1024×500 ✅ |
| 스크린샷 | `store-assets/01..07-*.png` | 1080×1920 ✅ 7장 |

스크린샷 순서(이대로 올리면 된다):

1. `01-home` — 홈. 랜덤 추천 + 오늘의 배틀 + 지금 맞는 메뉴
2. `02-roulette` — 랜덤 결과 "보쌈!" + 이걸로 찾기 + 공유
3. `03-worldcup-match` — 메뉴 월드컵 대결 화면
4. `04-worldcup-winner` — 우승 메뉴 + 주변에서 찾기
5. `05-ranking` — 음식 인기 랭킹
6. `06-mbti` — MBTI 음식 궁합
7. `07-nearby` — 주변 맛집 지도

> 스크린샷은 **웹 화면을 Playwright 로 찍었다.** 실기기 캡처를 쓰지 않는 이유:
> 해상도를 마음대로 못 맞추고, 광고가 있는 앱이면 테스트 광고 배너가 그대로 찍힌다.
> 다시 뽑으려면 `node scripts/store-shots.mjs`.

## 콘텐츠 등급 설문 — 예상 답변

| 질문 | 답 |
| --- | --- |
| 폭력 | 없음 |
| 성적 콘텐츠 | 없음 |
| 욕설 | 없음 |
| 통제 물질(술·담배·마약) | 없음 |
| 도박 | 없음 — 룰렛·월드컵은 **메뉴 고르기**지 금전 도박이 아니다 |
| 사용자 간 상호작용 | **있음** (모임 채팅) → 아래 UGC 항목 확인 |
| 위치 공유 | **있음(선택 기능)** — 아래 주의 |

> 🔴 **위치가 다른 이용자에게 보인다.** 모임의 &lsquo;근처에 있는 멤버 찾기&rsquo;를 켜면
> 정확한 좌표가 `nearby_presence` 에 올라가고, 그 테이블은 **로그인한 누구나 읽을 수 있다**
> (RLS `FOR SELECT USING (true)`). 5분 필터는 화면에서만 걸린다.
> 데이터 보안 선언에서 **위치 = 수집함 + 공유함 + 정확한 위치** 로 답해야 한다.
> 아니라고 적으면 거짓 선언이 된다.

> 🔴 **모임 채팅이 있다.** 구글 UGC 정책은 신고·차단·모더레이션을 요구한다.
> BLOCKPOP 은 자유 채팅 때문에 출시 직전에 정해진 문구 고르기로 바꿔야 했다.
> meogja 는 **멤버 강퇴**가 있지만 **신고 창구가 없다.** 최소한 신고 메일 링크라도 붙여야 한다.
